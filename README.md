# Mechanized Formalization of Qunity Semantics and Type System in Lean 4

A formalization of the type system and semantics of the Qunity programming language, introduced in [the POPL 2023 paper "Qunity: A Unified Language for Quantum and Classical Computing"](https://dl.acm.org/doi/10.1145/3571225) by Voichick et al.

This project uses the Lean 4 theorem prover and aims to be a faithful mechanization of Qunity first, before possible extensions.
